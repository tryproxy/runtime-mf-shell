# Documentation routing

For routine engineering work, do not scan `docs/` recursively.

1. Start at `docs/README.md` and open only the route relevant to the task.
2. Read `docs/reserach.local/CURRENT.md` only when current platform state is relevant.
3. Read focused architecture, integration, testing, or operations documents only when the router points to them.
4. Do not read `docs/archive/**` or `docs/reserach.local/done/**` unless the task explicitly asks for history, archaeology, or comparison with a past decision.

Source code, package locks, emitted artifacts, and published package releases remain authoritative for implemented behavior.
