## Reading policy

- `guide/` contains maintained, public integration instructions.
- `reserach.local/CURRENT.md` is the compact platform snapshot.
- Documents below `reserach.local/architecture`, `integration`, `operations`, and `testing` are focused references: open them only for that subject.
- [`archive/`](./archive/README.md) and `reserach.local/done/` are historical evidence, not current instructions.

The historic onboarding paths remain as short redirects so existing links keep working.
